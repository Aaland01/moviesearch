# Moviesearch

Project website for searching for movies by year and/or title, individual movie data, and people involved in the movies. 

## Frameworks
React, Vite, Reactstrap + bootstrap

### Extra Modules
AGgrid - Tables for movies and people. Customized Material theme. 
ChartJS + React Chartjs 2 - Chart component for a persons ratings
Sass - For compiling custom scss

## Styling
Main CSS consists of bootstrap CSS, with minor variations using scss variable mapping and overriding, defined in bootstrap docs for customising. Changes are primarily in colors to reflect wanted theme.
